# Fight for Knowledge — نسخه دیجیتال سه‌بعدی

راهنمای تعاملی سه‌بعدی اتاق‌فرار «حلقه انسانی» برای داوران. ساخته‌شده طبق [`BUILD_SPEC.md`](BUILD_SPEC.md)؛ شخصیت ایجنت‌ها از [`src/data/AGENTS.md`](src/data/AGENTS.md) خوانده می‌شود.

**استک:** Three.js 0.169 · TypeScript · Vite 6 · بدون بک‌اند · خروجی استاتیک برای GitHub Pages.

## اجرا

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # تست‌های پذیرش منطقی (بخش ۱۳)
npm run build      # tsc + vite build → dist/
```

> روی ویندوزهایی که Smart App Control دارند، باینری بومی rollup تازه بلاک می‌شود؛ به همین دلیل rollup در `package.json` روی `4.62.4` پین شده است (`overrides`).

## پلان طبقه (نسخه دوم)

- **بدون راهرو.** چهار اتاق گوشه یک مربع ۲×ROOM_HALF از هر ربع را پر می‌کنند و هشت‌ضلعی اتاق اصلی مستقیم از گوشه داخلی هر چهارتا بریده می‌شود. نتیجه: هر اتاق هم با دو همسایه‌اش دیوار مشترک دارد، هم مستقیم به اتاق اصلی می‌چسبد.
- **هر یال فقط یک در.** `DOOR_AT` برای هر یال یک مختصات جهانی می‌دهد و در همان‌جا **یک** شیء در ساخته می‌شود که از هر دو اتاق قابل‌کلیک است. هیچ دو در رو‌به‌رویی در بازی نیست.
- **مقیاس:** ثابت `S = 0.66` («۶۰ درصد» اندازه قبلی). همه پراپ‌ها در همان فضای ۱۰×۱۰ قدیمی نوشته می‌شوند و داخل یک گروه `scale = S` می‌نشینند، پس چیدمان داخلی اتاق‌ها دست‌نخورده مانده است.
- **`WALL_FACE = 4.72`** — دیوارها نیم‌ضخامت به داخل اتاق نشسته‌اند تا دیوار اتاق همسایه رویشان نیفتد؛ هر شیء دیواری باید روی این فاصله نصب شود، نه روی ۴٫۸۶ قدیمی.
- **محو دیوار:** دوربین هر اتاق از بیرون نقشه به داخل نگاه می‌کند، پس دو دیوار بیرونی محو می‌شوند و دو دیوار رو به مرکز دیده می‌شوند. **پوسترها هم با دیوار خودشان محو می‌شوند**؛ بنابراین هر پوستری که باید خوانده شود روی دیوارهای رو به مرکز نصب شده است.
- **داکت کولر** به‌جای دریچه کف دیوار: یک مجرا با دو توری، بالای `D51` در اتاق ۱ و بالای `D25` در اتاق ۲. **دوطرفه است** — باز شدن از هر سمت سمت دیگر را هم باز می‌کند.

## فونت‌ها

- **Peyda** (`src/assets/fonts/PeydaVF.ttf`، متغیر): کل رابط و نوشته‌های غیردیواری.
- **Paradox** (`src/assets/fonts/Paradox-Regular.ttf`): فقط نوشته‌های روی دیوارها (پوسترها، تخته، پنل‌ها). Paradox حروف لاتین ندارد؛ متن‌های لاتین معماها (LIAR، NH₃، Maxwell…) روی دیوار خودکار با Peyda کشیده می‌شوند. صحنه بعد از لود هر دو فونت ساخته می‌شود.

## دو حالت

صفحه ورود فقط یک دکمه **شروع** دارد؛ بازی در حالت **راهنما** و از **نمای کلی نقشه** باز می‌شود و جابه‌جایی بین دو حالت از همان دو دکمه داخل نوار بالا انجام می‌شود. رابط فقط فارسی است.

نوار بالا یک کلید **تم روشن/تاریک** دارد. تم فقط لایه DOM را عوض می‌کند؛ رنگ‌های صحنه سه‌بعدی از خود کد می‌آیند و ثابت می‌مانند. برچسب‌ها و تول‌تیپ‌هایی که مستقیم روی بوم می‌نشینند هم در هر دو تم تیره می‌مانند تا روی صحنه تیره خوانا باشند. تم در `localStorage` (`ffk3d.theme`) ذخیره می‌شود و پیش‌فرضش از `prefers-color-scheme` می‌آید.

- **راهنما (داور):** روی هر پراپ یک ⓘ؛ کارت با شناسه، نوع قفل، جواب، «چرا» و نیت طراحی؛ دکمه «باز کن» برای رد کردن معما؛ پرش آزاد به هر اتاق. در این حالت دوربین آزاد است و **هم‌تیمی‌ها جابه‌جا نمی‌شوند**.
- **بازی:** تیم چهارنفره (یک نفر در هر اتاق گوشه). نوار بالا هر **پنج** اتاق را فهرست می‌کند و عدد روی هر دکمه یعنی چند هم‌تیمی داخلش است؛ کلیک روی اتاقی که کسی در آن نیست رد می‌شود. هر نفر فقط از راه درها حرکت می‌کند. تایمر ۱۲۰ دقیقه.

## چت ایجنت‌ها

تماس مستقیم از مرورگر به `POST {BASE_URL}/chat/completions`. پیش‌فرض: `https://api.avalai.ir/v1` و `deepseek-v4.1-flash`. **کلید API را کاربر وارد می‌کند**؛ فقط در `localStorage` همان مرورگر می‌ماند و فقط به provider انتخابی می‌رود. هیچ کلیدی در ریپو نیست — یک کلید زنده را هرگز در سورس نگذارید.

قواعد ویژه در منطق اعمال می‌شوند، نه فقط در پرامپت:
- **دوان:** ۱ تلاش برای مگ‌لاک D35. حدس غلط ⇒ دوان بدون تماس شبکه جواب بی‌روح می‌دهد. هر سکه پیداشده (`64` زیر فرش، `101` پشت قفسه) که عددش به دوان داده شود (تایپ در چت یا دکمه «دادن سکه») یک تلاش اضافه می‌کند.
- تاریخچه به ۱۶ پیام آخر محدود است.

## تصاویر معماها

فایل‌های `public/assets/puzzles/*` فعلا placeholderهای ۲×۲ پیکسلی‌اند (تا سایت ۴۰۴ ندهد). تصویر واقعی تیم را **با همان نام** جایگزین کنید؛ برنامه placeholder را از اندازه تشخیص می‌دهد و تا آن موقع بازسازی خودش را نشان می‌دهد. `npm run placeholders` فقط فایل‌های گم‌شده را می‌سازد.

`assetTexture()` در `engine/textures.ts` همین کار را برای صحنه سه‌بعدی هم می‌کند: اول نسخه بازسازی‌شده را می‌کشد و اگر فایل واقعی موجود بود، همان تکسچر را جایگزین می‌کند. پس **کافی است فایل را با نام درست در پوشه بگذارید**؛ هیچ کدی عوض نمی‌شود.

## استقرار

این پروژه در پوشه `source/` ریپوی `AliNasrollahpour.github.io` است و Pages مستقیم از ریشه برنچ `main` سرو می‌کند؛ پس بیلد باید در ریشه ریپو باشد. بعد از هر تغییر:

```bash
cd source
npm install
npm run publish:root   # build + کپی dist به ریشه ریپو (index.html، assets/، .nojekyll)
```

سپس از ریشه ریپو کامیت و push کنید. `vite.config.ts` با `base: './'` است، پس سایت در هر مسیری کار می‌کند.
