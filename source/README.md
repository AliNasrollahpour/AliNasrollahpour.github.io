# Fight for Knowledge — نسخهٔ دیجیتالِ سه‌بعدی

راهنمای تعاملیِ سه‌بعدیِ اتاق‌فرارِ «حلقه انسانی» برای داوران. ساخته‌شده طبقِ [`BUILD_SPEC.md`](BUILD_SPEC.md)؛ شخصیتِ ایجنت‌ها از [`src/data/AGENTS.md`](src/data/AGENTS.md) خوانده می‌شود.

**استک:** Three.js 0.169 · TypeScript · Vite 6 · بدون بک‌اند · خروجیِ استاتیک برای GitHub Pages.

## اجرا

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # تست‌های پذیرشِ منطقی (بخش ۱۳)
npm run build      # tsc + vite build → dist/
```

> روی ویندوزهایی که Smart App Control دارند، باینریِ بومیِ rollupِ تازه بلاک می‌شود؛ به همین دلیل rollup در `package.json` روی `4.62.4` پین شده است (`overrides`).

## چه چیزی کجاست

| مسیر | نقش |
|---|---|
| `src/data/game-data.ts` | **منبعِ واحدِ حقیقت**: اتاق‌ها، ۹ یالِ در (per-side)، همهٔ معماها و جواب‌ها، کلیدها، سکه‌ها، سرنخ‌ها، مسیرهای برد |
| `src/data/AGENTS.md` + `agents.ts` | سیستم‌پرامپت‌ها عیناً از AGENTS.md پارس می‌شوند (قوانینِ مشترک + بلوکِ هر ایجنت) |
| `src/game/` | منطقِ خالص و تست‌پذیر: `GameState`، `DoorLogic` (گیتینگ)، `PuzzleController` (ارزیابی، سقفِ Devan، برد/باخت)، `AgentChat` |
| `src/engine/` | صحنهٔ Three: ساختِ ۵ اتاق از روی نقشه، دوربین، raycast/hover، نشان‌های ⓘ |
| `src/ui/` | لایهٔ DOM: HUD، پنلِ قفل‌ها، ترمینالِ چت، کارتِ راهنما، مسیرها، صفحهٔ پایان |
| `tests/logic.test.ts` | ۶۸ تست برای چک‌لیستِ بخش ۱۳ |

## فونت‌ها

- **Peyda** (`src/assets/fonts/PeydaVF.ttf`، متغیر): کلِ رابط و نوشته‌های غیرِدیواری.
- **Paradox** (`src/assets/fonts/Paradox-Regular.ttf`): فقط نوشته‌های روی دیوارها (پوسترها، تخته، پنل‌ها). Paradox حروفِ لاتین ندارد؛ متن‌های لاتینِ معماها (LIAR، NH₃، Maxwell…) روی دیوار خودکار با Peyda کشیده می‌شوند. صحنه بعد از لودِ هر دو فونت ساخته می‌شود.

## دو حالت

- **راهنما (داور):** روی هر پراپ یک ⓘ؛ کارت با شناسه، نوع قفل، جواب، «چرا» و نیتِ طراحی؛ دکمهٔ «باز کن» برای رد کردنِ معما؛ پرشِ آزاد به هر اتاق از نقشه؛ پنلِ شخصیت + شروع‌کننده‌ها + نمونه‌گفت‌وگوی آفلاین در ترمینال؛ پنلِ «مسیرهای برد».
- **بازی:** تیمِ چهارنفره (یک نفر در هر اتاقِ گوشه). بینِ هم‌تیمی‌ها از HUD جابه‌جا شو؛ هر نفر فقط از راهِ درها حرکت می‌کند. تایمرِ ۱۲۰ دقیقه.

## چتِ ایجنت‌ها

تماسِ مستقیم از مرورگر به `POST {BASE_URL}/chat/completions`. پیش‌فرض: `https://api.avalai.ir/v1` و `deepseek-v4.1-flash`. **کلیدِ API را کاربر وارد می‌کند**؛ فقط در `localStorage` همان مرورگر می‌ماند و فقط به providerِ انتخابی می‌رود. هیچ کلیدی در ریپو نیست — یک کلیدِ زنده را هرگز در سورس نگذارید.

قواعدِ ویژه در منطق اعمال می‌شوند، نه فقط در پرامپت:
- **دوان:** ۱ تلاش برای مگ‌لاکِ D35. حدسِ غلط ⇒ دوان بدونِ تماسِ شبکه جوابِ بی‌روح می‌دهد. هر سکهٔ پیداشده (`64` زیرِ فرش، `101` پشتِ قفسه) که عددش به دوان داده شود (تایپ در چت یا دکمهٔ «دادنِ سکه») یک تلاش اضافه می‌کند.
- تاریخچه به ۱۶ پیامِ آخر محدود است.

## تصاویرِ معماها

نُه فایلِ `public/assets/puzzles/*` فعلاً placeholderهای ۲×۲ پیکسلی‌اند (تا سایت ۴۰۴ ندهد). تصویرِ واقعیِ تیم را **با همان نام** جایگزین کنید؛ برنامه placeholder را از اندازه تشخیص می‌دهد و تا آن موقع یک بازسازیِ SVG (شبکهٔ عصبی، لگوها، اسکرابل، کاغذِ زیرِ میز) نشان می‌دهد. `npm run placeholders` فقط فایل‌های گم‌شده را می‌سازد.

## استقرار

این پروژه در پوشهٔ `source/` ریپوی `AliNasrollahpour.github.io` است و Pages مستقیم از ریشهٔ برنچِ `main` سرو می‌کند؛ پس بیلد باید در ریشهٔ ریپو باشد. بعد از هر تغییر:

```bash
cd source
npm install
npm run publish:root   # build + کپیِ dist به ریشهٔ ریپو (index.html، assets/، .nojekyll)
```

سپس از ریشهٔ ریپو کامیت و push کنید. `vite.config.ts` با `base: './'` است، پس سایت در هر مسیری کار می‌کند.
