# Fight for Knowledge — حلقه انسانی

نسخه دیجیتال سه‌بعدی اتاق‌فرار «Fight for Knowledge» برای داوران. سایت: https://alinasrollahpour.github.io/

| مسیر | چیست |
|---|---|
| `index.html`، `assets/` | بیلد آماده که GitHub Pages مستقیم سرو می‌کند — دستی ویرایش نکنید |
| `source/` | سورس پروژه (Three.js + TypeScript + Vite)؛ راهنمای کامل در [`source/README.md`](source/README.md) |
| `archive/` | محتوای قبلی سایت: صفحه شخصی و اپ چت `fightforknowledge` (لینک‌های قدیمی `/fightforknowledge/…` به همین‌جا ریدایرکت می‌شوند) |

نسخه دقیق قبلی هم در برنچ `archive/main-2026-10-29` و تگ `archive-main-2026-10-29` نگه داشته شده است.

## به‌روزرسانی سایت

```bash
cd source
npm install
npm run publish:root
```

بعد از ریشه ریپو کامیت و push کنید.
